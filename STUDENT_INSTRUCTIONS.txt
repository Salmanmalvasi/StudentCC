# 🐛 StudentCC Debug Version - Instructions for 1st Year Students

## ⚠️ **IMPORTANT: Only for students who CANNOT see their timetable**

### 📥 **Step 1: Install the Debug Version**

1. **Download**: `StudentCC_V_1.4.0_DEBUG.apk` (53MB)
2. **Uninstall** the regular StudentCC app first (if you have it)
3. **Install** the debug version
4. **Note**: This debug version uses more battery and may be slower (only temporary!)

### 🔍 **Step 2: Reproduce the Issue**

1. **Open** the StudentCC debug app
2. **Login** with your credentials
3. **Sync your data** - Pull down to refresh on the home screen
4. **Wait** for sync to complete (you'll see a notification)
5. **Check your timetable** - Does it show classes or is it empty?

### 📋 **Step 3: Get the Debug Log**

**Method 1: Using the Debug Button in App (EASIEST)**
1. Open the **StudentCC debug app**
2. Go to **Profile/Settings**
3. Look for **"🐛 Timetable Debug Log"** button
4. Tap it to open the debug screen
5. Tap **"💾 Save to Downloads"**
6. Go to your **Downloads** folder
7. Find the file: **StudentCC_Timetable_Debug.txt**
8. **Share** this file

**Method 2: Copy from the App**
1. Open the debug screen (see Method 1 steps 1-4)
2. Tap **"📋 Copy Log to Clipboard"**
3. Paste it into WhatsApp and send to me

**Method 3: Using File Manager (if buttons don't work)**
1. Open your **File Manager** app
2. Go to **Downloads** folder
3. Find the file: **StudentCC_Timetable_Debug.txt**
4. **Share** this file

### 📤 **Step 4: Share the Log with Me**

Send the log via **WhatsApp group** or DM me with:
1. The debug log (copied text or the file)
2. Your **year** (1st/2nd/3rd/4th)
3. **Branch** (CSE/ECE/EEE etc.)
4. **Campus** (Chennai/Vellore/Bhopal/Amaravati)
5. Screenshot of empty timetable (if possible)

### 📊 **What the Log Contains**

The debug log shows:
- ✅ Which semester was selected
- ✅ How many courses were found
- ✅ How many timetable slots were found
- ✅ Exact data received from VTOP
- ✅ Any errors that occurred

### 🔒 **Privacy**

- ❌ Log does NOT contain your password
- ❌ Log does NOT contain personal information
- ✅ Log only contains technical data about timetable parsing
- ✅ Safe to share with developer

### 🔧 **After Sharing the Log**

1. You can **uninstall** the debug version
2. **Reinstall** the regular StudentCC app
3. Wait for the next update with the fix!

### ❓ **Troubleshooting**

**Q: I don't see the "Timetable Debug Log" button in settings**
A: Make sure you installed the DEBUG version (file size: 53MB). The regular version doesn't have this button.

**Q: The debug log is empty**
A: You need to sync your data first. Pull down to refresh on the home screen, wait for it to complete, then check the debug log again.

**Q: I can't find the file in Downloads**
A: Try using the "Copy Log to Clipboard" button instead, then paste and send the text directly.

**Q: App crashes when I try to sync**
A: Please send me a screenshot of the crash and any error messages you see.
