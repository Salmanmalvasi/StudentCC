# StudentCC 1.6.1

- Fixed missing CGPA in the GPA Calculator by restoring the original VTOP grade-history reader. CGPA and earned credits refresh after Full Sync and Quick Sync, with the familiar calculator layout.
- Added separate StudentCC and UniCC class insights, grade estimates and grade ranges. Relative S predictions start at 80 marks when the calculated class threshold is not higher. Predictions show their assumptions and contributor counts.
- Grade projections for embedded courses check theory and laboratory pass requirements separately, so a strong component cannot hide a failed component.
- Added a class-level 9+ CGPA tally. Students can choose sharing during sign-in or enable it directly from Profile, and can remove their contribution by turning sharing off.
- Improved cumulative marks, indicators for updated marks, and exam schedule display.
- Improved compatibility for sync updates and app messages across supported Android versions.
- Improved in-app update downloads and Android installer handoff, including package, version and checksum checks.

Android version code: `21`.
